About data storage units

This calculator uses binary prefixes (1KB = 1,024 Byte). Internet/network speeds are usually shown in bits (Kb, Mb, Gb), while file sizes use bytes (KB, MB, GB) — remember that 1 byte = 8 bits when comparing the two.

UnitEquals (in bytes)
Bit0.125 Byte
Kilobyte (KB)1,024 Byte
Megabyte (MB)1,048,576 Byte
Gigabyte (GB)1,073,741,824 Byte
Terabyte (TB)1,099,511,627,776 Byte

Common examples

  • 1GB = 1,024MB
  • A "100Mbps" internet plan tops out around 12.5MB/s (100 ÷ 8).
  • A smartphone photo is roughly 3-5MB, so a 128GB phone can hold about 25,000-40,000 photos.
